## MongoDB Design

## User Schema

Fields:
- name
- email
- password
- phone
- role
- profileImage
- createdAt


## Book Schema

Fields:
- title
- author
- price
- quantity
- pdfFile
- image


## Issue Schema

Fields:
- userId
- bookId
- issueDate
- returnDate
- status


## Payment Schema

Fields:
- userId
- bookId
- amount
- paymentId
- paymentStatus
